Ce répertoire contient la version 3.8 du plug-in "Diffusion3" destiné à être utilisé sous le logiciel REAPER.

Notez bien que cette version est temporaire, expérimentale, et peut, si elle le désire, ne pas fonctionner correctement, ceci, bien sûr, à l'insu de mon plein gré. Elle est cependant diffusée sous une licence publique quelconque, qui vous autorise à en faire le meilleur usage possible.

Installer "Diffusion-3.jsfx", "Diffusion3-Colors.jsfx-inc" et "AKAI-APCmini-1.jsfx-inc" dans le répertoire "Effects" de REAPER, ou un sous répertoire de celui-ci. Pour rappel, le répertoire de REAPER s'obtient par le menu "Options > Show REAPER resource path in explorer/finder..."

Le fichier "Diffusion-1.txt" est un exemple de description d'une configuration simple : projection d'une source stéréo sur une installation quadriphonique. Placer ce fichier dans un répertoire de nom "Diffusions", lui-même placé dans le répertoire "Data" de REAPER.

"Diffusion-Test-0.RPP" est un exemple de projet utilisant la description ci-dessus. Placer un fichier stéréo dans l'une des pistes "clip xxx" pour le projeter sur les HP de votre installation.
